Depok, West Java vs Paya Terubong climate

How the climate of Depok, West Java, Indonesia compares with Paya Terubong, Malaysia, 1,497 km apart: month-by-month averages from modelled 1981–2010 data for each town’s own location.

Main differences

  • Paya Terubong is 0.2 °C (0.3 °F) warmer over the year: 26.5 °C against 26.3 °C.
  • The biggest monthly difference is in June, when Paya Terubong is 0.9 °C warmer (Depok, West Java 26.3 °C, Paya Terubong 27.2 °C).
  • Hottest-month day highs: Depok, West Java 32.4 °C (September), Paya Terubong 31.6 °C (March). Coldest-month night lows: Depok, West Java 20.8 °C, Paya Terubong 21.5 °C.
  • Depok, West Java gets 2% more rain and snow a year: 3,273 mm against 3,200 mm.
  • Depok, West Java gets about 262 more hours of bright sunshine a year (2,669 h against 2,407 h; about 1961–1990).
  • They are in different hemispheres, so their seasons are reversed.
