Depok, West Java vs Tangerang climate

Main differences

  • Tangerang is 0.6 °C (1.1 °F) warmer over the year: 26.9 °C against 26.3 °C.
  • The biggest monthly difference is in October, when Tangerang is 0.7 °C warmer (Depok, West Java 26.8 °C, Tangerang 27.5 °C).
  • Hottest-month day highs: Depok, West Java 32.4 °C (September), Tangerang 32.9 °C (September). Coldest-month night lows: Depok, West Java 20.8 °C, Tangerang 21.5 °C.
  • Depok, West Java gets 34% more rain and snow a year: 3,273 mm against 2,445 mm.
  • Depok, West Java gets about 46 more hours of bright sunshine a year (2,669 h against 2,623 h; about 1961–1990).
