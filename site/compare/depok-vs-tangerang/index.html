Depok, West Java vs Tangerang climate

How the climate of Depok, West Java, Indonesia compares with Tangerang, Indonesia, 32 km apart: month-by-month averages from modelled 1981–2010 data for the ~10 km area around each town.

Main differences

  • Tangerang is 0.5 °C (1.0 °F) warmer over the year: 27.0 °C against 26.5 °C.
  • The biggest monthly difference is in June, when Tangerang is 0.6 °C warmer (Depok, West Java 26.4 °C, Tangerang 27.1 °C).
  • Hottest-month day highs: Depok, West Java 31.5 °C (September), Tangerang 31.3 °C (September). Coldest-month night lows: Depok, West Java 21.8 °C, Tangerang 23.1 °C.
  • Depok, West Java gets 35% more rain and snow a year: 3,160 mm against 2,341 mm.
  • Depok, West Java gets about 46 more hours of bright sunshine a year (2,669 h against 2,623 h; about 1961–1990).
