How the climate of Bandung, Indonesia compares with Depok, West Java, Indonesia: month-by-month averages from modelled 1981–2010 data for each town’s own location.

Main differences

  • Depok, West Java is 2.9 °C (5.3 °F) warmer over the year: 26.3 °C against 23.4 °C.
  • The biggest monthly difference is in August, when Depok, West Java is 3.3 °C warmer (Bandung 23.2 °C, Depok, West Java 26.5 °C).
  • Hottest-month day highs: Bandung 29.3 °C (September), Depok, West Java 32.4 °C (September). Coldest-month night lows: Bandung 17.3 °C, Depok, West Java 20.8 °C.
  • Depok, West Java gets 34% more rain and snow a year: 3,273 mm against 2,449 mm.
  • Depok, West Java gets about 215 more hours of bright sunshine a year (2,669 h against 2,454 h; about 1961–1990).
