Depok, West Java vs South Tangerang climate

How the climate of Depok, West Java, Indonesia compares with South Tangerang, Indonesia, 17 km apart: month-by-month averages from modelled 1981–2010 data for each town’s own location.

Main differences

  • South Tangerang is 0.3 °C (0.5 °F) warmer over the year: 26.7 °C against 26.3 °C.
  • The biggest monthly difference is in October, when South Tangerang is 0.4 °C warmer (Depok, West Java 26.8 °C, South Tangerang 27.2 °C).
  • Hottest-month day highs: Depok, West Java 32.4 °C (September), South Tangerang 32.3 °C (September). Coldest-month night lows: Depok, West Java 20.8 °C, South Tangerang 21.4 °C.
  • Depok, West Java gets 13% more rain and snow a year: 3,273 mm against 2,884 mm.
  • Depok, West Java gets about 28 more hours of bright sunshine a year (2,669 h against 2,641 h; about 1961–1990).
