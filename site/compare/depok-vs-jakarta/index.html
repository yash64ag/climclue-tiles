Depok, West Java vs Jakarta climate

How the climate of Depok, West Java, Indonesia compares with Jakarta, Indonesia, 21 km apart: month-by-month averages from modelled 1981–2010 data for each town’s own location.

Main differences

  • Jakarta is 0.5 °C (0.9 °F) warmer over the year: 26.8 °C against 26.3 °C.
  • The biggest monthly difference is in October, when Jakarta is 0.6 °C warmer (Depok, West Java 26.8 °C, Jakarta 27.4 °C).
  • Hottest-month day highs: Depok, West Java 31.4 °C (September), Jakarta 31.3 °C (September). Coldest-month night lows: Depok, West Java 21.4 °C, Jakarta 22.8 °C.
  • Depok, West Java gets 30% more rain and snow a year: 3,273 mm against 2,513 mm.
  • Depok, West Java gets about 21 more hours of bright sunshine a year (2,669 h against 2,648 h; about 1961–1990).
