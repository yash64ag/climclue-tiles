Depok, West Java vs Jakarta climate

Main differences

  • Jakarta is 0.3 °C (0.5 °F) warmer over the year: 26.8 °C against 26.5 °C.
  • The biggest monthly difference is in October, when Jakarta is 0.4 °C warmer (Depok, West Java 26.9 °C, Jakarta 27.4 °C).
  • Hottest-month day highs: Depok, West Java 31.5 °C (September), Jakarta 31.5 °C (September). Coldest-month night lows: Depok, West Java 21.8 °C, Jakarta 22.5 °C.
  • Depok, West Java gets 17% more rain and snow a year: 3,160 mm against 2,701 mm.
  • Depok, West Java gets about 21 more hours of bright sunshine a year (2,669 h against 2,648 h; about 1961–1990).
