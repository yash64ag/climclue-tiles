Bekasi vs Depok, West Java climate

How the climate of Bekasi, Indonesia compares with Depok, West Java, Indonesia, 26 km apart: month-by-month averages from modelled 1981–2010 data for the ~10 km area around each town.

Main differences

  • Bekasi is 0.3 °C (0.5 °F) warmer over the year: 26.8 °C against 26.5 °C.
  • The biggest monthly difference is in October, when Bekasi is 0.4 °C warmer (Bekasi 27.4 °C, Depok, West Java 26.9 °C).
  • Hottest-month day highs: Bekasi 31.5 °C (September), Depok, West Java 31.5 °C (September). Coldest-month night lows: Bekasi 22.5 °C, Depok, West Java 21.8 °C.
  • Depok, West Java gets 19% more rain and snow a year: 3,160 mm against 2,659 mm.
  • Depok, West Java gets about 18 more hours of bright sunshine a year (2,669 h against 2,651 h; about 1961–1990).
