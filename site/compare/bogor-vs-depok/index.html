Bogor vs Depok, West Java climate

How the climate of Bogor, Indonesia compares with Depok, West Java, Indonesia, 22 km apart: month-by-month averages from modelled 1981–2010 data for each town’s own location.

Compare them on the globe ›

Main differences

  • Depok, West Java is 0.9 °C (1.5 °F) warmer over the year: 26.3 °C against 25.5 °C.
  • The biggest monthly difference is in October, when Depok, West Java is 1.0 °C warmer (Bogor 25.8 °C, Depok, West Java 26.8 °C).
  • Hottest-month day highs: Bogor 30.5 °C (September), Depok, West Java 31.4 °C (September). Coldest-month night lows: Bogor 20.5 °C, Depok, West Java 21.4 °C.
  • Bogor gets 10% more rain and snow a year: 3,591 mm against 3,273 mm.
  • Depok, West Java gets about 44 more hours of bright sunshine a year (2,669 h against 2,625 h; about 1961–1990).
