Bayan Lepas vs Depok, West Java climate

How the climate of Bayan Lepas, Malaysia compares with Depok, West Java, Indonesia, 1,491 km apart: month-by-month averages from modelled 1981–2010 data for each town’s own location.

Main differences

  • Bayan Lepas is 0.9 °C (1.6 °F) warmer over the year: 27.2 °C against 26.3 °C.
  • The biggest monthly difference is in June, when Bayan Lepas is 1.6 °C warmer (Bayan Lepas 27.9 °C, Depok, West Java 26.3 °C).
  • Hottest-month day highs: Bayan Lepas 32.3 °C (March), Depok, West Java 32.4 °C (September). Coldest-month night lows: Bayan Lepas 22.2 °C, Depok, West Java 20.8 °C.
  • Depok, West Java gets 19% more rain and snow a year: 3,273 mm against 2,748 mm.
  • Depok, West Java gets about 262 more hours of bright sunshine a year (2,669 h against 2,407 h; about 1961–1990).
  • They are in different hemispheres, so their seasons are reversed.
